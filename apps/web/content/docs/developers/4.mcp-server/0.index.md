The DTPR MCP server exposes the DTPR schema, datachain validation, datachain rendering, icon URL resolution, and the DTPR Agent Skills as [Model Context Protocol](https://modelcontextprotocol.io) tools, resources, and prompts. It is hosted at:

```
POST https://api.dtpr.io/mcp
```

It implements a read-only subset of the MCP **Streamable HTTP** transport (spec version `2025-06-18`) plus **MCP Apps** (SEP-1865) for the render flow.

## In this section

- [Connecting](/docs/developers/mcp-server/connection) — endpoint, `mcp-session-id` header, wire format, batching.
- [Envelope](/docs/developers/mcp-server/envelope) — `ok` / `err` payloads, `_meta.content_hash`, soft-failure semantics.
- [Resources](/docs/developers/mcp-server/resources) — the `ui://dtpr/datachain/view.html` MCP App resource.
- [Tools](/docs/developers/mcp-server/tools/overview) — the 12-tool registry, one page each.
- [Prompts](/docs/developers/mcp-server/prompts) — the seven DTPR Agent Skills plus their reference documents, served as MCP prompts so any MCP-aware harness can load them without a Claude-specific install.

## Tools at a glance

| Tool | Purpose |
|------|---------|
| [`list_schema_versions`](/docs/developers/mcp-server/tools/list-schema-versions) | Discover available schema releases. |
| [`get_schema`](/docs/developers/mcp-server/tools/get-schema) | Manifest for a single schema version. |
| [`list_categories`](/docs/developers/mcp-server/tools/list-categories) | Categories within a schema version. |
| [`list_elements`](/docs/developers/mcp-server/tools/list-elements) | Paginated element list with filters. |
| [`get_element`](/docs/developers/mcp-server/tools/get-element) | Single element with icon variants + symbol. |
| [`get_elements`](/docs/developers/mcp-server/tools/get-elements) | Bulk fetch, up to 100 element ids. |
| [`validate_datachain`](/docs/developers/mcp-server/tools/validate-datachain) | Validate a datachain instance; soft-failure. |
| [`render_datachain`](/docs/developers/mcp-server/tools/render-datachain) | Render a datachain + hand off to an iframe via `resources/read`. |
| [`get_icon_url`](/docs/developers/mcp-server/tools/get-icon-url) | Resolve a composed-icon SVG URL. |
| [`resolve_datachain`](/docs/developers/mcp-server/tools/resolve-datachain) | Bundle a datachain with the categories and elements it uses. |
| [`validate_resolved`](/docs/developers/mcp-server/tools/validate-resolved) | Validate a resolved datachain against its schema version. |
| [`get_translation_status`](/docs/developers/mcp-server/tools/get-translation-status) | Per-locale review status and reviewer flags. |

All tools share the same [envelope](/docs/developers/mcp-server/envelope) shape.
