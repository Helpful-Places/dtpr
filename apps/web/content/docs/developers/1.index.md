# Developer docs

These pages are for developers building on DTPR. The taxonomy, its icons and datachain validation are all served by a public, read-only API. There are two ways in:

- The [REST API](/docs/developers/rest-api/overview), at `https://api.dtpr.io/api/v2`. It returns JSON and SVG, needs no authentication, and can be called from the browser.
- The [MCP server](/docs/developers/mcp-server), at `POST https://api.dtpr.io/mcp`. It exposes the same schema, validation and rendering as Model Context Protocol tools, so an AI assistant can read the taxonomy and check a datachain.

Every MCP tool has a REST equivalent, so use whichever fits your client.

## Before you start

A datachain is the JSON that describes one system. Read [Datachain](/docs/concepts#datachain) in Concepts for its shape and a worked example, and [Schema version](/docs/concepts#schema-version) for why every request names a version. Turn on the developer view on the Concepts page to see the API field names next to each term.
