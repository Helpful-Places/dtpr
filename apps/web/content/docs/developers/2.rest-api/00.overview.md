The DTPR v2 REST API is a public, read-only JSON + SVG API hosted at:

```
https://api.dtpr.io/api/v2
```

It is the underlying HTTP contract behind the [MCP server](/docs/developers/mcp-server) — every MCP tool has a REST equivalent. Integrate against whichever surface fits your client.

## In this section

- [`GET /schemas`](/docs/developers/rest-api/schemas) — list schema versions and aliases.
- [`GET /schemas/:version/manifest`](/docs/developers/rest-api/manifest) — schema manifest (title, description, content hash).
- [`GET /schemas/:version/categories`](/docs/developers/rest-api/categories) — category list for a version.
- [`GET /schemas/:version/elements`](/docs/developers/rest-api/elements-list) — paginated element list with filters.
- [`GET /schemas/:version/elements/:element_id`](/docs/developers/rest-api/element-detail) — single element with variants + symbol.
- [`POST /schemas/:version/validate`](/docs/developers/rest-api/validate) — validate a datachain instance.
- [Icon routes](/docs/developers/rest-api/icons) — shapes, symbols, composed icons.
- [Pagination + fields + locales](/docs/developers/rest-api/pagination-and-fields) — cursor semantics, projection.
- [Errors](/docs/developers/rest-api/errors) — shared error shape and codes.

## Conventions

- **Authentication:** none. All endpoints are public. Optional `DTPR-Client: <name>` header moves you to a dedicated rate-limit bucket.
- **CORS:** all endpoints return `Access-Control-Allow-Origin: *` and are callable from any origin, including browser-side JavaScript on third-party sites. Exposed response headers: `X-Request-Id`, `DTPR-Content-Hash`, `Retry-After`.
- **Response headers:** version-scoped reads stamp `DTPR-Content-Hash` (hex content hash) and `Cache-Control`. The canonical version is echoed inside the JSON body as `"version"` — there is no `X-DTPR-Version` header.
- **Versioning:** the `:version` path segment accepts a canonical id like `ai@2026-04-16-beta` or an alias like `ai@latest`.
- **Errors:** see [Errors](/docs/developers/rest-api/errors) for the shared shape.
