# Quickstart

The DTPR API is a public, read-only REST API. No authentication is required. All endpoints support CORS.

::callout{type="info"}
**Which version?** [v2](/api/v2/overview) is the current, maintained API and is where new integrations should start — but it publishes only `ai@…` schema versions today. The **device** taxonomy shown below is served by the frozen [v1](/api/v1/overview) surface, which is preserved exactly as `dtpr.io` served it.
::

## Base URL

```
https://api.dtpr.io/api/v1
```

## Get all elements

Fetch every element in the DTPR taxonomy:

::code-group
```bash [curl]
curl https://api.dtpr.io/api/v1/elements
```

```javascript [fetch]
const response = await fetch('https://api.dtpr.io/api/v1/elements')
const elements = await response.json()
console.log(elements)
```
::

## Get elements for a datachain type

Fetch elements filtered to a specific datachain type (e.g., `device` or `ai`):

::code-group
```bash [curl]
curl https://api.dtpr.io/api/v1/elements/device
```

```javascript [fetch]
const response = await fetch('https://api.dtpr.io/api/v1/elements/device')
const elements = await response.json()
console.log(elements)
```
::

## Filter by locale

Add the `?locales=` query parameter to a **typed** endpoint to receive only specific languages:

::code-group
```bash [curl]
curl "https://api.dtpr.io/api/v1/elements/device?locales=en"
```

```javascript [fetch]
const response = await fetch('https://api.dtpr.io/api/v1/elements/device?locales=en,fr')
const elements = await response.json()
console.log(elements)
```
::

::callout{type="warning"}
Do not add `?locales=` to the untyped `/api/v1/elements` endpoint — it returns `500 Server Error`. This is a defect in the frozen v1 surface, reproduced deliberately rather than repaired. The typed element and category endpoints filter correctly.
::

## Get categories for a datachain type

```bash
curl https://api.dtpr.io/api/v1/categories/device
```

## Get an icon

Icons are served from the same host, namespaced per API version:

```bash
curl https://api.dtpr.io/api/v1/icons/identifiable_video.svg
```
