---
title: get_translation_status
description: Review status of each locale in a schema version, plus the flags reviewers raised.
---

::callout{type="info"}
Check this before authoring or publishing a datachain in a non-English locale: it says whether a fluent speaker has reviewed the wording yet.
::

## Summary

Given a `version`, returns one entry per locale in the version's manifest and the flags translators and reviewers raised. Same payload as [`GET /schemas/:version/translations`](/rest/translations).

## Input

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `version` | `string` | yes | Schema version. |
| `locales` | `string[]` | no | Locales to report on. Aliases resolve (`tl` → `fil`, `zh-TW` → `zh-Hant`). Omit for every locale. |
| `flag_status` | `"open" \| "resolved" \| "wontfix" \| "all"` | no | Which flags to return. Default `"open"`. |

## Output

```json
{
  "ok": true,
  "data": {
    "version": "dtpr@2026-09-01-beta",
    "source_locale": "en",
    "locales": [
      {
        "locale": "km",
        "status": "machine_reviewed",
        "register": "Standard modern Khmer, no zero-width spaces",
        "translated_by": "claude-opus-5-5",
        "reviewed_by": "claude-opus-5-5 (independent pass, 24 corrections)",
        "updated_at": "2026-10-05",
        "summary": "Acceptable for beta; needs a native pass before physical signage. …",
        "flag_counts": { "open": 13, "resolved": 0, "wontfix": 0 }
      }
    ],
    "flags": [
      {
        "id": "…",
        "locale": "km",
        "kind": "native_review",
        "status": "open",
        "raised_by": "reviewer",
        "keys": ["elements/….yaml#title"],
        "note": "…",
        "targets": [{ "type": "element", "id": "…", "field": "title" }]
      }
    ]
  },
  "meta": { "content_hash": "sha256-…", "version": "dtpr@2026-09-01-beta" }
}
```

Locale `status` is `source` for the canonical locale, otherwise `unverified`, `machine_draft`, `machine_reviewed` or `human_reviewed`. `flag_counts` counts every flag for the locale regardless of `flag_status`. See the [REST page](/rest/translations) for every field.

## Errors

| Code | Meaning | Fix |
|------|---------|-----|
| `invalid_arguments` | Missing / malformed arguments, or an unknown `flag_status`. | Fix the call. |
| `unknown_version` | Version is not registered. | Call `list_schema_versions`. |

## Example

::code-group
```bash [curl]
curl -s https://api.dtpr.io/mcp \
  -H 'content-type: application/json' \
  --data '{
    "jsonrpc":"2.0","id":1,
    "method":"tools/call",
    "params":{
      "name":"get_translation_status",
      "arguments":{
        "version":"dtpr@2026-09-01-beta",
        "locales":["km"]
      }
    }
  }'
```

```json [tools/call]
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_translation_status",
    "arguments": {
      "version": "dtpr@2026-09-01-beta",
      "locales": ["km"],
      "flag_status": "all"
    }
  }
}
```
