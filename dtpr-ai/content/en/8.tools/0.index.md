Tools for working directly with DTPR for AI artifacts — in your browser, or in your design tool.

::card-group
  ::card
  ---
  title: Datachain visualizer
  to: /tools/datachain
  ---
  Paste, drop, or deep-link a `DatachainInstance` JSON to validate it
  against the live API and render it the same way `DtprDatachain` would
  in your own app. Save chains to a personal localStorage collection.
  ::

  ::card
  ---
  title: Figma plugin
  to: /icons/figma-plugin
  ---
  Generate a Figma component library of every DTPR element and icon,
  straight from the live API. Download, run once, publish the result as
  a Team Library.
  ::
::
