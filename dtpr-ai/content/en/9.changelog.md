## 2026-08-26

### Schema

- **`dtpr@2026-09-01-beta` — consolidated datachain type** ([#326](https://github.com/helpful-places/dtpr/pull/326))
  The `ai` and `device` taxonomies merge into a single `dtpr` type, so the version prefix moves from `ai@` to `dtpr@` and every category's `datachain_type` follows. Content carries over from `ai@2026-08-24-beta`: 137 elements across 14 categories, with `collection` (capture technology) and `manifestation` (the form the output takes when people encounter it) holding the device-side concepts. The `data_flow` subchain is `collection → input_dataset → processing → output_dataset → manifestation`.
  The `ai@` line is superseded and receives no further versions; versions already published under it stay served, so pinned consumers keep resolving.
  References: [Versions & releases](/concepts/versions-and-releases), [Taxonomy](/taxonomy).
- **Icon overhaul across five categories.** `collection` and `manifestation` get 15 literal device/encounter glyphs in place of borrowed symbols; the five `rights` elements that shared one target glyph get distinct action glyphs; 10 legacy fine-line composites are redrawn as single bold objects legible at 36px. Icon counts are unchanged — 468 composed icons.
  References: [Icon composition](/icons), [Symbols](/icons/symbols).

### Site

- **Version selector spans the rename.** The taxonomy and datachain surfaces list both `dtpr@` and `ai@` versions in one selector, newest first, so the lineage stays browsable across the type id change.

## 2026-05-07

### MCP

- **`prompts/` capability — Agent Skills served over MCP.** The MCP server now registers each of the seven DTPR Agent Skills (and the two shared reference documents) as named MCP prompts. Any MCP-aware client (Cursor, Continue, Cline, Claude Desktop, the Anthropic Agent SDK, custom clients) can list and load them via `prompts/list` + `prompts/get` without a Claude-specific install. Bundled at build time from `plugin/dtpr/skills/` — single source of truth shared with the Claude plugin install path.
  - New CLI: `pnpm --filter ./api bundle:skills` regenerates `api/src/mcp/prompts/skills.generated.ts`.
  - Drift detection: `pnpm test:plugin` fails if a skill or reference exists in the plugin tree but not in the API bundle (or vice versa).
  - References: [Prompts](/mcp/prompts), [Other harnesses](/plugin#other-harnesses).

### Plugin

- **Plugin v0.3.0 — symbol-design split + seven-skill studio.** Symbol drafting moves out of `dtpr-element-design` into a dedicated `dtpr-symbol-design` skill that proposes three SVG variants per round with a local HTML preview. The plugin docs also pick up the previously-undocumented `dtpr-translate` skill from 0.2.1, so the public skill table now lists all seven peers. References: [Skills](/plugin/skills), [`dtpr-symbol-design`](/plugin/skills/symbol-design), [`dtpr-translate`](/plugin/skills/translate).

## 2026-04-18

### Icons

- **Icon composition pipeline** ([#270](https://github.com/helpful-places/dtpr/pull/270))
  Shape × symbol × variant composition with `default` / `dark` / context-colored variants and the WCAG `innerColor` rule. Adds pre-baked R2 point-read with on-the-fly fallback.
  New REST routes: `GET /api/v2/shapes/:shape.svg`, `GET /api/v2/schemas/:version/symbols/:symbol_id.svg`, `GET /api/v2/schemas/:version/elements/:element_id/icon[.<variant>].svg`.
  New MCP tool: [`get_icon_url`](/mcp/tools/get-icon-url).
  References: [Icon composition](/icons), [REST icon routes](/rest/icons).

### Site

- **`dtpr.ai` microsite placeholder** ([#271](https://github.com/helpful-places/dtpr/pull/271))
  Docus + Nuxt 4 skeleton deployed on Cloudflare Workers with a D1 binding for content queries. Minimal landing; no documentation yet.

## 2026-04-17

### @dtpr/ui

- **Component library + `render_datachain` MCP tool** ([#267](https://github.com/helpful-places/dtpr/pull/267))
  Three subpath exports: `@dtpr/ui/core` (10 framework-neutral helpers), `@dtpr/ui/vue` (6 Vue 3 SFCs), `@dtpr/ui/html` (SSR via `renderDatachainDocument`). Default stylesheet wraps everything in `@layer dtpr` and exposes a full CSS custom-property token set.
  New MCP tool: [`render_datachain`](/mcp/tools/render-datachain). New MCP resource: `ui://dtpr/datachain/view.html` (MCP Apps iframe handoff).
  References: [Vue reference](/ui/vue), [Core reference](/ui/core), [HTML SSR](/ui/html), [Theming](/ui/theming).

### MCP

- **Read path on Cloudflare Workers** ([#265](https://github.com/helpful-places/dtpr/pull/265))
  Hand-rolled JSON-RPC over HTTP handler (workerd nodejs_compat can't load the SDK's CJS Ajv dep). Supported methods: `initialize`, `notifications/initialized`, `tools/list`, `tools/call`, `resources/list`, `resources/read`, `ping`. Shared `ok` / `err` envelope with `_meta.content_hash` / `_meta.version`.
  Initial tools: `list_schema_versions`, `get_schema`, `list_categories`, `list_elements`, `get_element`, `get_elements`, `validate_datachain`.
  References: [Connecting](/mcp/connection), [Envelope](/mcp/envelope).

### REST v2

- **`api.dtpr.io/api/v2` read path** ([#265](https://github.com/helpful-places/dtpr/pull/265))
  Public, read-only JSON + SVG. Opaque cursor pagination (`MAX_LIMIT = 200`), field/locale projection, `DTPR-Content-Hash` + `Cache-Control` on version-scoped responses, static CORS allow-list. `POST /schemas/:version/validate` runs shape + semantic validation and always returns HTTP 200.
  References: [REST v2](/rest), [Pagination & fields](/rest/pagination-and-fields), [Errors](/rest/errors).
