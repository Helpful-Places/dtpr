DTPR for AI est une taxonomie publique et un standard de divulgation. Si vous y faites référence — dans un article, un cours, un dépôt réglementaire, une politique de confidentialité ou une divulgation produit — merci de le citer. Le bloc ci-dessous est la citation canonique ; il est synchronisé avec le fichier [`CITATION.cff`](https://github.com/helpful-places/dtpr/blob/main/CITATION.cff) à la racine du dépôt, que GitHub affiche comme bouton **Citer ce dépôt** dans la barre latérale.

::callout{type="info"}
La traduction française complète de cette page est en cours. Les blocs BibTeX et les noms d'auteurs restent en anglais — ce sont les formes canoniques.
::

## Travaux que DTPR for AI cite

Lorsque le standard adapte du contenu issu de recherches externes, la source porte sa propre citation et licence ci-dessous. La provenance par élément vit dans le tableau `sources[]` de chaque élément (interrogeable via l'outil [MCP `get_element`](/plugin) ou l'endpoint REST [`GET /api/v2/schemas/:version/elements/:element_id`](/rest)) ; cette page est le résumé lisible.

### Taxonomie des préjudices AIAAIC

La catégorie risques (`ai__risks_mitigation`) adapte la taxonomie AIAAIC. Toute redistribution modifiée de ces éléments doit être publiée sous CC BY-SA 4.0 — voir la [page Attribution](/attribution) pour la portée complète de la clause ShareAlike.
