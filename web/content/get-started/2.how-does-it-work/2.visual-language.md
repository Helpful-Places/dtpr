# Visual Language


Visual languages are great at communicating complex information. Think about nutrition labels. Nutritional science can be incredibly difficult to understand. If every item at the grocery store came with a ten page scientific report then running your errands would be impossible. What nutrition labels do is provide a simplified, consistent layout to convey the most important information. 

DTPR does the same thing. Firstly, we start with elements. For each of the categories that make up the taxonomy, DTPR provides a set of open-source icons and plain language descriptions to describe different options. For example, when describing what kind of algorithm a system uses, DTPR has 12 different elements to choose from. 

DTPR also comes with clear guidance on how to arrange those icons.
