DTPR archive

Prototypes from when Digital Trust for Places & Routines was a Sidewalk Labs project. They are kept as published, apart from fixes needed to run them today. The current project lives at dtpr.io.

  • Vision (vision.dtpr.io) — the scroll-through microsite describing where DTPR was headed.
  • Interaction (prototype.dtpr.io) — the clickable sign-and-detail prototype for individual technologies.
  • Chatbot (chatbot.dtpr.io) — the Dialogflow assistant pages. The agent behind them no longer exists.
