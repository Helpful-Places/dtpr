# Interaction prototype

Clickable prototype of a DTPR sign and the detail pages behind it, one per
technology (`?technology=<id>`). The data is an export of the Sidewalk Labs-era DTPR Airtable
base (`allRecords.json`, `databaseContent.json`); nothing is fetched live.

Live at https://prototype.dtpr.io. It was first published at
`dtpr.sidewalklabs.com/dtpr_prototype/` and later on GitHub Pages; the QR code
on the sign now encodes the URL it is served from.
