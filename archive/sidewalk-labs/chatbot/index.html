DTPR chatbot prototype

A Sidewalk Labs experiment in answering questions about a place, a system, or a single component through a conversational assistant. Each page below embeds Google's Dialogflow Messenger, pointed at one agent and started on a different intent, with the place or component identified by its record in the DTPR Airtable base of the time.

The Dialogflow agent (f92d33ee-bfa0-4c27-9a5d-852381c861c2) and its Airtable-backed fulfillment were shut down with the Sidewalk Labs project. The pages load and the chat window opens, but it cannot answer.

  • Place — the library: “Library Assistant”, starting on learn-about-place.
  • System — the sustainability system, starting on learn-about-component.
  • Component — the computer-vision mirror, starting on learn-about-component.
